# Startsidans herofoto

Lägg ett foto här som `hero.webp` (eller `hero.jpg`/`hero.png`), så visas det
i bildrutan till höger i startsidans hero. Ingen kodändring behövs, se
`src/components/HomeHeroVisual.jsx`.

- Stående format runt 4:5, ca 1000 px brett, helst under 250 KB.
- Byt alt-texten `home.heroPhotoAlt` i `src/i18n/sv.js` och `en.js` så att den
  beskriver fotot.
- Bara bilder som InkRevenue har rätt att använda i sin egen marknadsföring.
